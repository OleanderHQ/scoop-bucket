# oleander Scoop bucket

[Scoop](https://scoop.sh) manifests for the [oleander CLI](https://oleander.dev/docs/cli).

```powershell
scoop bucket add oleander https://github.com/OleanderHQ/scoop-bucket
scoop install oleander
```

Upgrade with `scoop update oleander`.

`bucket/oleander.json` is written by the release workflow in [OleanderHQ/oleander](https://github.com/OleanderHQ/oleander) on every CLI release, so don't edit it by hand.
